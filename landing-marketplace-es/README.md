# Catálogo de Landings

Proyecto independiente para convertir la biblioteca visual extraída de WebsitePrompts.ai en un catálogo comercial en castellano.

- No modifica `german-landing-main`.
- Usa las capturas ya descargadas como referencia visual.
- Los prompts quedan fuera de la vista pública.
- La experiencia está pensada como una sección integrable luego dentro de la web principal.

## Desarrollo

```bash
npm install
npm run data
npm run dev
```
