Cree un sitio web para ortodoncistas profesionales llamado "Bright Smile Orthodontics" en Austin, TX. Pila de tecnología: React + Vite + TypeScript + Tailwind CSS + Framer Motion. Diseño: azul cielo primario (#0EA5E9), azul marino intenso secundario (#1E3A5F), coral CTA (#FF6B6B), fondo blanco. Secciones: barra de navegación con CTA "Reservar consulta gratuita", héroe dividido (título a la izquierda, foto de la oficina a la derecha), cuadrícula de servicios de 3 columnas (Invisalign, frenillos tradicionales, frenillos para adolescentes), banda de confianza con 4 estadísticas, control deslizante antes/después (3 pares), cómo funciona en 3 pasos, 3 tarjetas de testimonios, sección de seguro/financiamiento, biografía del médico con credenciales, acordeón de preguntas frecuentes (4 preguntas), banner de CTA, pie de página. Titular destacado: "Dientes más rectos, mayor confianza". Sublínea: "Invisalign y brackets para toda la familia. Consultas gratuitas, planes de pago flexibles". CTA principal: "Reservar consulta gratuita". Animaciones: el texto del héroe se desvanece 0,6 segundos, las tarjetas se desvanecen al desplazarse. Móvil: héroe apilado, tarjetas de servicio de ancho completo, barra adhesiva "Reservar ahora".
