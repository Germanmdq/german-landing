# Sitio web de DJ: AI Prompt

## Goal
Cree un sitio web de artista completo para **VØID**, un DJ y productor de música electrónica. Base negra pura, acento verde ácido y una estética que se lee como un osciloscopio de señales combinado con una editorial de artistas de alta gama. Esta no es una plantilla EDM genérica. Sin degradados de neón, sin neblinas moradas, sin confeti. Simplemente preciso, oscuro y vivo, como la música misma.

---

## Tech Stack
React + Vite + TypeScript + Tailwind CSS + Framer Motion (motion/react) + shadcn/ui + lucide-react

## Sistema de diseño - Colores

```css
:root {
  --void:       #000000;     /* pure black */
  --void-2:     #0a0a0a;
  --surface:    #111111;
  --border:     #1f1f1f;
  --border-hi:  #2e2e2e;
  --text:       #f0f0f0;
  --text-soft:  #555555;
  --text-dim:   #333333;
  --acid:       #aaff00;     /* acid green — the only accent */
  --acid-dim:   #6a9e00;
  --white:      #ffffff;
}
```

Fondo: `--void`. Texto: `--text`. Acento: `--acid`: se usa exclusivamente en puntos de navegación activos, botones de CTA, barras de forma de onda, subrayados al pasar el mouse y puntos de datos clave. Bordes: `--border` (1px). Tarjetas: `--surface`. Sin degradados ni efectos de desenfoque, excepto una navegación esmerilada. Radio cero en todas partes: todos los elementos cuadrados.

## Efectos visuales

### 1. Barras de forma de onda animadas (héroe fondo)
```css
.waveform {
  display: flex;
  align-items: center;
  gap: 3px;
  position: absolute;
  bottom: 0; left: 0; right: 0;
  height: 120px;
  padding: 0 var(--gutter);
  opacity: 0.15;
}
.bar {
  flex: 1;
  background: var(--acid);
  border-radius: 0;
  animation: wave var(--dur, 1.2s) ease-in-out infinite alternate;
  transform-origin: bottom;
}
@keyframes wave {
  from { scaleY: 0.1; }
  to   { scaleY: 1; }
}
```
Generar 80 barras. Cada barra obtiene un `--dur` aleatorio entre 0,6 s y 2,2 s y un "retraso de animación" aleatorio entre 0 y 1,5 s. Crea una forma de onda orgánica y respirable en todo el ancho del héroe. Verde ácido, baja opacidad, solo atmósfera.

## Responsive

- **Escritorio (≥1024px)**: Seguimiento de las columnas completas de la tabla, muestra la fila completa de la lista, aproximadamente 2 columnas, mezclas 3 columnas.
- **Tableta (768–1023px)**: la tabla de pistas colapsa la etiqueta/año, sobre las pilas en la imagen a continuación, mezclas 2+1.
- **Móvil (<768px)**: la tabla de pistas muestra NUM + TÍTULO + reproducción únicamente. Espectáculos: fecha + lugar apilados, botón a continuación. Mezclas: desplazamiento de una sola columna. Formulario de reserva en ancho completo. Titular de héroe `clamp(72px, 16vw, 100px)`.
