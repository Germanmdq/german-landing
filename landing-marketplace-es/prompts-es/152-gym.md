# Sitio web de Gym & Fitness Studio Prompt
# websiteprompts.ai

Cree un sitio web atrevido y lleno de energía para un gimnasio y un estudio de fitness llamado "APEX Gym" usando React + Vite + TypeScript + Tailwind CSS + Framer Motion (motion/react) + shadcn/ui + lucide-react.

## Diseño Sistema

### Colores
```css
:root {
  --background: 0 0% 5%;            /* near-black #0d0d0d */
  --foreground: 0 0% 96%;           /* white */
  --primary: 76 85% 50%;            /* electric lime #8fe619 */
  --primary-foreground: 0 0% 5%;
  --surface: 0 0% 9%;
  --surface-raised: 0 0% 13%;
  --muted-foreground: 0 0% 55%;
  --border: 0 0% 16%;
}
```

### Tipografía
- Importación: `https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;700&family=Inter:wght@300;400;500;600&display=swap`
- Titulares: Space Grotesk 700 — escala máxima, no disculpas
- Cuerpo: Inter 300–500
- Estadísticas/números: Space Grotesk 700, verde lima
